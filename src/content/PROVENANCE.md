# Bundled exercise provenance

The code bank contains 60 short exercises authored in this project for typing
practice: 20 Rust, 20 Python, and 20 JavaScript. They are never executed by the
app. The word bank is a curated, alphabetized set of common English words, not a
frequency-ranked dataset or a copy of another typing app's corpus. No network
service or user files supply exercises. Curation and exercise authoring were
AI-assisted during development.

Content pool version: 1. Exercise IDs are language plus a stable numeric ID;
exercise version starts at 1. Preserve IDs for unchanged exercises and increment
versions when text changes. The project distribution license remains an author
decision before release; do not infer a license from this provenance note.
